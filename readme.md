Сервис api для веб меню для различных ресторанов 

Какие хендлеры должны быть 

1) Регистрация нового ресторана
2) Регистрация нового меню. Всегда должно указываться к какому ресторану он относиться
3) Регистрация нового меню. Всегда указывать к какому меню его добавить 
4) Получение информации о ресторане 
5) Получение активного меню ресторана со всем списком блюд которые привязаны к этому меню
6) Получение всех существующих меню ресторана со статусом активности (без списка блюд)
7) Обновление конкретного меню 
8) Обновление конкретного блюда
9) Обновление информации конкретного ресторана
10) Удаление меню - вместе с меню должны удалиться и всеблюда которые к нему относяться
11) Удаление ресторана - также должна удалиться вся информация 
12) Сохранение корзины 

Все хендлеры которые приводят к изменению данных кроме сохранения корзины должны быть с авторизацией по JWT токену



Хранение
Информация хранится в монго базе 



Структура данных в грубой форме по сущностям
Ресторан 
  Id
  Название 
  Лого

Меню 
  id
  id ресторана
  Описание
  active 

Блюдо 
  id
  id меню
  Название
  Состав
  КБЖУ
  Цена
  Тип (опциональное)

Корзина 
  id
  id ресторана
  Список id блюд
  Статус (Закрыт/Открыт)
  Итоговая сумма (проставляется при закрытии)
